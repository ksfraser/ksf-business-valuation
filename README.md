# ksf_business_valuation

Business Valuation calculation engines — business logic. Part of the KSF calculation package family.

- Namespace: `Ksfraser\BusinessValuation`
- Framework: `ksfraser/ksf_modules_common` (`Ksfraser\ModulesCommon`)
- Exceptions: `ksfraser/exceptions`

## Engines
| Engine | Purpose |
|--------|---------|
| `BusinessValuationEngine` | Value a business for planning or sale. |
| `BuySellAgreementAnalyzer` | Analyze funding needs of a buy-sell agreement. |
| `SuccessionPlanningEngine` | Plan leadership / family-business succession. |
| `OverheadExpenseCalculator` | Compute business overhead for valuation. |
| `CostBenefitCalculator` | Compare costs vs benefits of planning options. |
